# What is this ?
It's an optimized version of "https://patra.citybus.gr" created with gemini with some extra features.<br><br>

Instead of putting all the available bus stops on the map on load, it loads just the bus stop names, in ascending order based on the distance from you.<br> 
Selecting a stop:<br> 
1. Displays its location and yours on the map
2. Shows the available buses and their live schedules

# Hosting
You will need to self host the website, you can use "vercel.com" for your personal use.
